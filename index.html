EchoinWhispr

Decentralized Social Protocol

Web3 Hedera IPFS

The Problem

Centralized social platforms give users no ownership over their identity, content, or data. Moderation decisions are opaque, and privacy is a feature toggle—not an architectural guarantee.

The Architecture

Chose Hedera Consensus Service (HCS) over Ethereum for sub-second finality at fractions of a penny — critical for real-time social interactions. Content addressed via IPFS with ECIES end-to-end encryption ensures message-level privacy. Smart contracts (Solidity) on Hedera Token Service (HTS) manage identity and access without a central authority.

Key Trade-offs

IPFS adds latency vs. centralized CDN storage, but guarantees censorship resistance. Merkle-tree verification adds compute overhead but enables trustless identity verification without a database.

Status

Live protocol — MVP deployed on Hedera testnet. Full mobile client in development.

VozParking

Voice-First Parking Companion

Expo SDK 55 Gemini AI Firebase RDW / NPR API

The Problem

Dutch drivers navigate fragmented parking data across multiple apps, inconsistent pricing, and real-time availability — all while keeping their hands on the wheel.

The Architecture

Voice-first interface using Gemini for natural language intent parsing, routed to a server-side aggregation layer that unifies RDW, NPR, and OSM APIs into a single ranked response. Local-first caching layer minimizes redundant API calls and keeps response times under 2 seconds.

Key Trade-offs

Gemini inference costs are higher than rule-based NLP — chose AI for intent flexibility across unpredictable voice patterns. Local caching offsets per-query cost by serving repeat requests from memory.

Status & Link

iOS production build actively tested in Dutch urban corridors. Live at vozparking.com.

Flutter / Dart Gemini AI Google ML Kit 5 Platforms

The Problem

Legal contracts and digital terms of service are notoriously dense and opaque for everyday users. Existing analysis tools are cloud-locked, single-platform, and lack seamless live screen or multi-format document ingestion.

The Architecture

Autonomous Agent System

Zero-Cost Agentic Workflow Architecture

n8n Qdrant Ollama

The Problem

Cloud AI APIs create vendor lock-in, expose sensitive data, and incur recurring costs that scale linearly with usage — prohibiting private, high-volume agentic workflows.

The Architecture

Designed a fully self-hosted agent architecture: Ollama serves local LLMs (Llama 3, Mistral), Qdrant provides vector search for RAG, and n8n orchestrates multi-agent pipelines with priority-based task queues and handoff protocols. No cloud dependency — zero marginal cost per inference.

Key Trade-offs

Local models (7B–13B parameters) trade absolute accuracy vs. GPT-4 for unlimited scaling at zero cost. Chose Qdrant over cloud vector DBs for data sovereignty — sensitive documents never leave the local network.

Status

Actively powering internal agency operations — content pipelines, CRM automation, and research agents.
